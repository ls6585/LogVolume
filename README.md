# 🪵 原木材积计算器

一个纯前端的在线原木材积计算器。输入一组原木数据后，**同时展示“公式计算”和“原木材积表（GB/T 4814）”两种结果**，并给出每行差值和整体合计，方便对比核对。

单个 HTML 文件，无需安装依赖、无需后端，直接用浏览器打开即可使用。

## 功能特点

- **双结果对比**：每根原木同时显示公式计算值与材积表值，以及两者的差值
- **多行批量计算**：支持添加、删除多行，自动汇总总根数和总材积
- **批量粘贴导入**：每行一条，格式为 `小头直径,长度,根数,大头直径`，根数和大头直径可省略
- **根数默认为 1**：新增行、导入、留空时都按 1 根计算
- **响应式界面**：电脑端为表格，手机端自动变为卡片式布局
- **深色模式**：自动跟随系统明暗设置
- **实时计算**：输入即出结果，无需点击按钮

## 使用方法

1. 直接用浏览器打开 `index.html`，或访问 GitHub Pages 地址
2. 填写小头直径（cm）、长度（m）、根数；大头直径为选填
3. 页面右侧（手机端为卡片下方）即时显示两种计算结果

批量导入示例（每行一条）：

```
20,4,10
26,6,5,30
8,3,20
```

## 计算规则

### 1. 公式计算

使用输入的原始直径与长度，不取整：

| 情况 | 公式 |
| --- | --- |
| 填写了大头直径（平均直径法） | `V = π/4 × ((D小 + D大) / 2)² × L ÷ 10000` |
| 未填大头直径（圆柱近似） | `V = π/4 × D小² × L ÷ 10000` |

圆柱近似按小头直径计算，未考虑原木上小下大的尖削度，结果通常偏小。

### 2. 原木材积表

先按国标规则“进级”，再代入国标材积公式，结果保留 3 位小数：

- **检尺径**：4–12 cm 按 1 cm 去尾取整；14 cm 及以上按 2 cm 去尾取偶
- **检尺长**：按 0.2 m 去尾
- **小径原木（检尺径 4–12 cm）**：
  `V = 0.7854 × L × (D + 0.45L + 0.2)² ÷ 10000`
- **大径原木（检尺径 ≥ 14 cm）**：
  `V = 0.7854 × L × [D + 0.5L + 0.005L² + 0.000125 × L × (14 − L)² × (D − 10)]² ÷ 10000`
- **适用范围**：检尺径 ≥ 4 cm，检尺长 2–30 m，超出范围显示“—”

## 注意事项

- 材积表一列的数值由上述国标公式生成，**并非内置官方整张表**，公式系数请以官方 **GB/T 4814-2013** 为准。
- 用于正式交易、结算前，请与官方标准核对典型数值。
- 如需调整公式或系数，修改源码中的 `tbl()` 函数即可。
